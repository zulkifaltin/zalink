# 🔗 ZALink - Kişisel Link Sayfası

ZALink, modern tasarım ve 3D animasyonlar ile sosyal medya ve web profillerinize erişim sağlayan kişisel link sayfasıdır.

## ✨ Özellikler

- **3D Tilt Efekti**: VanillaTilt kütüphanesi kullanarak dinamik 3D döndürme efekti
- **Parlak Efekti (Glare)**: Hover üzerinde ışılama animasyonu
- **Responsive Tasarım**: Tüm cihazlarda düzgün görünüm
- **Modern UI**: Glassmorphism ve backdrop blur efektleri
- **Favicon**: Özel logo favicon'u

## 🔗 Sosyal Linkler

Sayfada şu platformlara hızlı erişim sağlanmaktadır:
- 📝 Blog
- 📸 Instagram
- 🎥 YouTube
- 💼 LinkedIn
- 𝕏 Twitter
- 💻 GitHub
- Sınırsız eklenebilen açık kaynak kod.

## 🛠️ Teknolojiler

- HTML5
- CSS3 (Glassmorphism, Backdrop Filter)
- Vanilla JavaScript
- VanillaTilt.js - 3D tilt efekti için
- Font Awesome - İkonlar için

## 🚀 Kurulum

1. Repository'yi klonlayın:
```bash
git clone https://github.com/zulkifaltin/ZALink.git
cd ZALink
```

2. `index.html` dosyasını bir tarayıcıda açın veya yerel bir web sunucusu kullanın:
```bash
python3 -m http.server 8000
```

3. Tarayıcıda `http://localhost:8000` adresine gidin

## 📝 Düzenleme

- Sosyal medya linklerini `index.html` dosyasında güncelleyebilir ve ekleyebilirsiniz
- Renkleri `style.css` dosyasında değiştirebilirsiniz
- 3D efekt parametrelerini `module.js` dosyasında ayarlayabilirsiniz
